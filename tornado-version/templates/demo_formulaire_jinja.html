1. Formulaire HTML (method="POST" → self.get_body_argument)

Code Python Tornado exécuté par ce formulaire

class FormulaireFormationHandler(tornado.web.RequestHandler):
    def get(self):
        # 1. Rendu du template HTML avec échappement auto-XSS :
        self.render("formations.html", formations=CATALOGUE)

    def post(self):
        # 2. Lecture des champs <input name="..."> via self.get_body_argument :
        titre = self.get_body_argument("titre", default="").strip()
        duree = int(self.get_body_argument("duree_jours", default="5"))
        salle = self.get_body_argument("salle", default="Salle A")
        self.set_status(201)
        self.render("formations.html", formations=CATALOGUE)

3. Tester aussi en ligne de commande avec curl -d

Sans -H "Content-Type: application/json", l'option -d de curl envoie exactement un formulaire application/x-www-form-urlencoded lu par self.get_body_argument(...) : 

curl -i -X POST http://127.0.0.1:8888/api/sandbox/formulaire-formation \
  -d "titre=Formation+Tornado+Templates&duree_jours=4&salle=Salle+B"

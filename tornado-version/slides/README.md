# Support de Présentation — Python Tornado & Ingénierie des APIs (136 Diapositives)

Ce répertoire contient l'édition autonome du support de projection (**136 diapositives au format 16:9**) conçu pour le Bootcamp ISGP.

## Contenu

- `slides_bootcamp_tornado_api.html` : Fichier HTML unique 100 % autonome (styles, moteur de navigation et 136 diapositives intégrés, zéro dépendance réseau).
- Données sources modulaires :
  - `../data/slides_part_a.py` (Diapositives 1 à 72 — Parties 0 à 4)
  - `../data/slides_part_b.py` (Diapositives 73 à 136 — Parties 5 à 8)
  - `../data/slides_data.py` (Assembleur et indexation des 9 parties)

## Utilisation pendant la formation

1. **Via le serveur unifié ou la PWA en ligne** : Ouvrir `/slides/tornado` (`https://abdelouahabb.github.io/isgp-api/slides/tornado/index.html`).
2. **Hors-ligne depuis une clé USB ou le poste formateur** : Double-cliquer directement sur `slides_bootcamp_tornado_api.html` dans n'importe quel navigateur moderne.
3. **Raccourcis clavier du mode projecteur** :
   - `Flèche Droite` / `Espace` / `PageDown` : Diapositive suivante
   - `Flèche Gauche` / `PageUp` : Diapositive précédente
   - `F` : Basculer en **Plein Écran Paysage**
   - `G` : Ouvrir la **Grille visuelle des 136 diapositives**
   - `/` : Rechercher instantanément un terme ou un code HTTP
   - `T` : Basculer entre **Mode Sombre (Cinéma)** et **Mode Clair (Salle éclairée)**
   - Bouton **Exporter PDF** : Impression paysage `16:9` (1 diapositive exacte par page)

Comment fonctionne cette page dans FastAPI ? (Rendu Serveur Jinja2Templates + Décodage de Formulaire Form(...))

Cette page est rendue côté serveur via templates.TemplateResponse(request=request, name="demo_formulaire_jinja.html", context={...}). Lorsque vous cliquez sur « Envoyer le Formulaire (POST) », le navigateur n'envoie pas du JSON, mais un corps encodé en Content-Type: application/x-www-form-urlencoded (ex: titre=API+FastAPI&formateur=Dr+Benali&duree_jours=5&salle=Salle+A). FastAPI extrait et valide chaque champ grâce aux paramètres déclarés avec Form(...) (python-multipart), insère la formation dans SQLite et régénère le tableau HTML avec une boucle Jinja2 {% for f in formations %}.

    titre: str = Form(..., min_length=3),
    formateur: str = Form("Intervenant ISGP"),
    duree_jours: int = Form(..., ge=1, le=30),
    salle: str = Form("Salle A"),
):

Comment fonctionne cette page ? (Rendu Serveur Jinja2 + Traitement de Formulaire request.form)

Cette page est rendue côté serveur par Flask via render_template("demo_formulaire_jinja.html", formations=..., erreurs=...). Lorsque vous cliquez sur « Envoyer le Formulaire (POST) », le navigateur n'envoie pas du JSON, mais un corps encodé en Content-Type: application/x-www-form-urlencoded (ex: titre=API+Flask&formateur=Dr+Benali&duree_jours=5&salle=Salle+A). Flask extrait chaque champ grâce à request.form.get("nom_du_champ"), valide les données, insère la formation dans SQLite et régénère le tableau HTML avec une boucle Jinja2 {% for f in formations %}.
